# Stickers

Put image files in this directory.

Recommended filename format:

`<short-id>.<png|jpg|webp|gif>`

Example index entry:

```json
{
  "id": "speechless-01",
  "file": "speechless-01.webp",
  "url": "https://cdn.jsdelivr.net/gh/yishu-ziyu/chatgpt-stickers@main/stickers/speechless-01.webp",
  "emotion": ["speechless", "disbelief"],
  "tone": ["dry", "funny"],
  "tags": ["离谱", "无语", "真的假的"],
  "usage": "For absurd or unbelievable moments in casual chat.",
  "aliases": ["speechless", "wtf", "真的假的"],
  "intensity": 2
}
```
